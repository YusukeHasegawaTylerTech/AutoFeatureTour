RMS-6654: "FOIA Request Agency Setting"

Components: Agency Settings (Record Request), Record Request entry (Referenced Records)

Description: A new agency setting page, "FOIA Request Prompt Default", under Record Request agency settings (behind the EnableRecordsRequestAiReview feature flag, Record Request license). It has two parts:
- Records Request Types: a multi-select of request types for which AI analysis is available. If none are selected, AI analysis is not available on any type.
- Rules: a grid of rules (Rule Name, Rule Description, Active) with add, edit, inactivate, reactivate and delete. The AI references active rules and cites a rule by its Rule Name.
On a Record Request, the "Review with AI" button on Referenced Records is only shown when the request's type is one of the selected request types.

Acceptance criteria:
- The FOIA Request Prompt Default page is reachable from Agency Settings > Record Request and shows the Records Request Types and Rules sections.
- A request type can be selected and saved on the page.
- A rule can be added with a Rule Name and Rule Description and appears in the Rules grid as Active.
- The Review with AI button on a Record Request's Referenced Records appears only for the selected request types.
