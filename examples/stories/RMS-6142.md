RMS-6142 child: "Publish MD IBR fields in Dynamic and Standard Reporting"

Components: Dynamic Reporting, Enterprise Print Designer (EPD), Standard Reports (Reporting)

Description: Publish the following fields in Dynamic Reporting:
- Household Code: Case > Case Subject > Victim > Domestic > Victim-Offender Relationship (val set)
- Hate Bias Status: Case > Supplemental Information (val set)
- Hate Group Name: Case > Offenses > Case Offense Circumstance (val set)
Also publish these fields for the Case Standard Detail Report; do not default them to print on the report.

Acceptance criteria:
- Verify field availability and report output for Dynamic Reporting.
- Verify field availability and report output for Enterprise Print Designer forms.
- Verify field availability and report output for standard Case Detail configured reports (available, not printed by default).
