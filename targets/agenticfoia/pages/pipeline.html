How a scanned PDF is read and redacted · all recognition runs on this machine

When the file is uploaded and analyzed

1
Find pages without text
PdfPig

Pages with real text use it directly. A page with no text is a picture.

2
Render the page
PDFiumPDFtoImage

Drawn as an image at 200 DPI, the same resolution the export uses.

3
Read the words
Tesseract 5 OCR

Each word, its line, and its box in pixels.

4
Save text + word map
SHA-256

The word map is stored with the file and tied to its fingerprint.

5
Suggest redactions
AI language model

Gets the text only, never the image. In production via the CJIS gateway.

When the clerk exports

6
Check the fingerprint
SHA-256

If the file changed since it was read, the export stops.

7
Render the page again
PDFium

Same 200 DPI, so the saved word boxes line up exactly.

8
Paint over approved words
SkiaSharp

Solid black, a few pixels wider than each word, into the pixels themselves.

9
Build a new PDF
PdfPig

From the images only: no text layer, no metadata.

10
Read it again
Tesseract 5 OCR

If any approved word can still be read, the export is refused.
